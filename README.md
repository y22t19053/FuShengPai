# 浮生牌 · 观测者的镜子

一副扑克牌，一套五行九宫规则，一次结构化的自我观测。

## 这是什么

浮生牌是一套独立的认知工具。它以扑克牌为载体，以五行生克、九宫推演、体用关系为底层逻辑，帮助你在面对问题时获得一个结构化的思考框架。

你得到的不是“吉”或“凶”的断言，而是一面镜子——它把模糊的、纠缠的、不敢面对的东西，清晰地反射回来。

## 核心特点

- **原创规则体系**：五行对应、J/Q/K归土、大小王为变数、差值系统、时间线坍缩——所有规则独立设计，可审计，可复现
- **纯本地运行**：所有数据存储在浏览器的 `localStorage` 中，不上传任何信息。断网也能使用完整的规则引擎
- **开源**：GPL-3.0 协议。你可以查看、修改、分发
- **AI 可选且自主**：如需 AI 解读，需要自行填写 API Key。请求从浏览器直连 AI 服务商，不经过任何中转服务器
- **不恐吓**：解读文案不制造焦虑，不给死亡倒计时，不卖开运物
- **免费**：没有付费墙，没有广告，没有“分享解锁”

## 规则概览

### 牌面与五行

| 牌 | 五行 | 阴阳 |
|---|------|------|
| ♥ 红桃 (A-10) | 火 | 阳 |
| ♦ 方块 (A-10) | 金 | 阳 |
| ♣ 梅花 (A-10) | 木 | 阴 |
| ♠ 黑桃 (A-10) | 水 | 阴 |
| 所有 J、Q、K | 土 | 按花色 |
| 大王 | 天 | 阳 |
| 小王 | 人 | 阴 |

J、Q、K 全部属土，意为“社会角色”，性别在此失效。

### 体用
从 52 张牌（去掉大小王）中抽取两张作为体用。体用抽出后不放回牌堆，作为整个牌阵的固定坐标原点。

- **体**：你、问卦人、事情的主体
- **用**：外部环境、对方、事情的走向

### 大小王
确认体用后，将大小王插入剩余 50 张牌中重新洗牌。

- **大王**：天意、贵人、不可抗力
- **小王**：智谋、转机、巧计

大小王的数值为 0，不参与常规生克判定。

### 九宫
九宫按后天八卦方位排列：

```
4(巽) 9(离) 2(坤)
3(震) 5(中) 7(兑)
8(艮) 1(坎) 6(乾)
```

放牌入宫后，系统自动检测“天机线”——三个连成一线的宫位，自动确定起因、经过、结果。其余宫位根据空间关系获得时间身份（起因的过去、结果的未来等）。

### 差值
```
差值 = | 宫位数字 - 牌面数值 |
```
A=1, 2-10=对应数字, J=1, Q=2, K=3, 大小王=0。差值代表现实与“理想状态”的偏离程度。

### 生克关系
以体牌为“我”：

| 关系 | 含义 |
|------|------|
| 生我 | 大吉 |
| 克我 | 大凶 |
| 同我 | 平 |
| 我生 | 小凶 |
| 我克 | 小吉 |

## 三种使用方式

- **在线抽牌**：在网页上完成完整占卜流程，牌背朝上，盲抽
- **手动录入**：手边有实体扑克牌，在线下完成抽牌和布阵，用网页记录牌面并生成解读
- **懒人一键**：自动完成所有步骤，直接查看解读

浮生牌的设计目标之一，是让你最终脱离网页，仅凭一副实体扑克牌和这套规则，就能独立完成观测。

## 隐私与安全

- 所有数据存储在浏览器的 `localStorage` 中
- 不收集、不上传、不分享任何用户信息
- AI 解读的 API Key 由用户自行填写，请求由浏览器直接发送至 AI 服务商
- 可以完全离线使用规则引擎和本地解读
- 没有埋点、没有分析工具、没有第三方脚本
