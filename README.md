🃏 浮生牌 · FuShengPai
一面镜子，不是一盏灯。

浮生牌是一个开源的、基于扑克牌的决策辅助工具。

随手打开，抽一副牌，得到一点启发。

不装神弄鬼，不搞宗教，不做心理测试，不说废话。

📖 它是什么

你有个烦心事。

不知道怎么选，或者心里其实已经有答案了，只是不敢承认。

打开浮生牌——输入问题，抽牌，布阵，看解读。

仅此而已。

它只是一个网页。

不是 app，不是 exe，不需要安装，不收集任何数据。

你愿意，可以只用本地引擎；你想深入，可以接自己的 AI Key，或者复制提示词发给任意 AI。

它最像的参照物，是网络上一二十块钱给你抽牌的塔罗占卜师。

只不过那个行业骗子太多，而我们是一面镜子。

🪞 核心哲学

牌面是一面镜子。

镜子不能让你变得更牛逼。

但镜子可以让你看到你自己有多牛逼。

善易者不卜——但人总需要做决策。

使用浮生牌，不是迷信它，而是相信自己的能力。

占卜的目的不是预言未来，而是帮你做出当下的决定。

浮生牌存在的意义，不是告诉你“会发生什么”，

而是提醒你“你自己其实知道该怎么选”。

❌ 它不是

不是信息收集工具——纯前端，零数据上传

不是宗教信仰——没有任何宗教色彩

不是算命——不预测未来，只帮你看清当下

不是心理测试——不贴标签，不做性格分析

不是正能量鸡汤——不说废话，不打鸡血

不是娱乐八卦玩具——它有用，不是消遣

🗡️ 文案标准

浮生牌的解读文案，遵守以下原则：

不讲古词。你说一句用户听不懂的话，等于放屁。

不装逼。“官鬼持世，此事忧疑”——占卜师自己说不清楚才拽这些。

不扒用户。“你表面坚强但内心柔软”——这种巴纳姆效应的屁话，用户会觉得被冒犯。

不搞“缺少一个机会就会出头”的鸡汤——纯放屁。

该给的情绪价值还是得给。

即使是一个工具，也不能冷冰冰。

心理层面的承接不是骗人，是让人觉得自己被看见了。

🎲 关于随机

浮生牌最底层的坚持：杜绝伪随机。

我极度反感那种“点按钮瞬间在代码库里随机生成结果”的占卜方式。

那不是抽牌，那是函数调用。

浮生牌要做到的是：在最大程度上模拟现实中的出牌。

牌局具有现实可复刻性——

两个平行世界里，一个人抽实体牌，一个人用浮生牌，抽出的牌完全一致。

你选哪一张，比随机更重要。

⚖️ 张力指数

张力指数，一句话定义：这局牌的拉扯程度。

原则上来讲，玄学是不能量化的。

但总有人喜欢看数值，就像总有人喜欢问“甩棍和匕首对打哪个能赢”。

这种东西不该影响产品的判断，但你给它一个数值，反而能避免很多麻烦。

张力指数就是那个按钮——

它不替你做决定，只把牌局里的松紧、冲突与节奏，换算成一个能读懂的数字。

（曾用名“榴莲指数”，因图形过于猎奇已移除；数值与色条沿用，文案已收敛。）
