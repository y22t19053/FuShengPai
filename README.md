# 浮生牌 · 观测者的镜子

> 一副扑克牌，一套五行九宫规则，一次结构化的自我观测。
> **这里没有答案，只有一面镜子。**

浮生牌是一个开源、免费、纯前端的占卜与自我观测工具。它不连接任何服务器，不收集数据，不贩卖焦虑。它只是把一副普通的扑克牌，变成一个让你重新看清自己处境的角度。

**它不是算命。它是一个思考工具。** 你可以在这里放下一个具体的困扰，通过抽牌和牌阵映射，让模糊的问题变得可见、可拆解、可应对。

---

## 为什么有浮生牌？

市面上有些占卜，要么靠巴纳姆话术骗钱，要么堆砌术语装神弄鬼。它们利用人对未知的恐惧，剥夺人的判断力。

浮生牌做的事情正相反：

- **不预测未来** —— 未来由你当下的行动决定。
- **不替你做决定** —— 牌面只是投影，最后的落笔权永远在你。
- **不隐藏逻辑** —— 五行生克、宫位差值、旺衰判定，所有推算过程都写在代码里，可查、可验、可拆解。
- **不窥探隐私** —— 你的数据只存在你的浏览器里，不经过任何中转服务器。
- **不说鬼话** —— 所有解读都是人话，你能看懂，用得上。

它的价值不在于“准”，而在于“有用”——帮你看到之前忽略的东西。

## 核心玩法

### 三步起局

1. **起念** — 写下你真正想问的事。问题越具体，牌面越清晰。
2. **立极** — 从牌堆中选出体牌（代表你）和用牌（代表所问之事）。
3. **布阵** — 插入大小王后将剩下牌放入九宫，凭直觉落牌，生成基于 13 个维度的交叉解读。每个维度可折叠展开，想看哪个点哪个。

### 十三维交叉解读

每次解局，系统会强制交叉融合以下 13 个维度：

| 维度 | 说明 |
|------|------|
| 宫位属性 | 该宫位对应的八卦方位及五行属性 |
| 五行生克 | 体用之间、宫位与牌面之间的生克关系 |
| 数字差值 | 宫位数字与牌面数字的偏移程度，映射现实与预期的落差 |
| 旺衰状态 | 判断当前能量处于旺/相/休/囚/死中的哪一档 |
| 天机线阶段 | 起因、经过、结果的时空定位 |
| 时间线映射 | 同一事件在过去、现在、未来的不同投影 |
| 四柱八字 | 结合阳历/阴历出生时间的四柱信息（可选） |
| 求测类别 | 支持两级分类：感情→复合 / 财运→正财 等 |
| 求测姓名 | 姓名五行对牌面解读的微调（可选） |
| 补充信息 | 你补充的任何背景信息，都可能影响细节判断 |
| 社会角色适配 | 适配现代关系语境（如性别角色、身份设定等） |
| 逻辑工具 | 内置 5W2H 与 SWOT 框架，引导理性拆解 |
| 意图关键词 | 从问题中提取的关键词对应的牌面映射 |

### 周期运程

日运、周运、月运、季运、年运。同一个抽牌系统在不同时间尺度上的投影

### AI 深度解读（可选）

- 你需要自行填写 API Key（支持 DeepSeek、OpenAI、Claude、Gemini、千问、Kimi、智谱等）。
- Key 只存在于你的浏览器本地，所有请求由你的浏览器直连第三方 AI 服务商，浮生牌不经过任何中转。
- AI 不推翻规则引擎的判断，只负责在原有结论上进行语言润色与心理逻辑梳理。
- 不想填 Key？点“复制提示词”，将牌局和解读一键粘贴到任意 AI 工具里

## 快速开始

```powershell
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可。

### 构建与部署

```powershell
npm run build
```

把生成的 `dist/` 文件夹丢到任何静态托管平台（GitHub Pages / Netlify / Vercel）即可。

## 项目结构

```
/
├── index.html              # 页面入口
├── style.css               # 暗夜金主题样式
├── src/
│   ├── data.js             # 静态数据：五行/牌组/九宫/分类/API配置
│   ├── engine.js           # 核心算法：洗牌/差值/天机线/四柱
│   ├── chaos.js            # 混沌引擎：真随机种子生成
│   ├── entropy.js          # 熵采集：从用户交互中收集随机源
│   ├── metaphor.js         # 比喻生成器：将符号翻译成画面
│   ├── ai.js               # AI 厂商接口封装（含超时重试）
│   ├── storage.js          # localStorage 读写与数据导出
│   ├── state.js            # 全局状态管理
│   ├── constants.js        # 可调数值常量
│   ├── durian.js           # 榴莲指数计算
│   ├── ui/                 # UI 交互模块
│   │   ├── ui-render.js    # 所有页面结构渲染
│   │   ├── ui-drag.js      # 点选/拖拽逻辑
│   │   ├── ui-modal.js     # 弹窗/Toast/引导/分享
│   │   └── ui-anim.js      # CSS 动画注入
│   ├── texts/              # 文案模块
│   │   ├── texts-readings.js  # 规则词库与生成引擎
│   │   └── index.js        # 文案统一出口
│   └── philosophy/         # 伦理层
│       ├── ethics.js       # 伦理拦截（软性引导）
│       └── covenant.js     # 占卜公约（禁用绝对化词汇）
```

## 关于“准不准”

浮生牌不承诺任何“准确率”。因为人生不是算术题。

如果一个系统告诉你“你的命运已经确定了”，请先想一想：那它为什么还需要收费？

真正有用的占卜，不告诉你未来，而是帮你看见——**你一直知道，但不敢承认的东西。**
