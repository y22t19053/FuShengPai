# 浮生牌 · 观测者的镜子

一副扑克牌，一套五行九宫规则，一次结构化的自我观测。

**浮生牌不是算命工具，而是一面中立、冷眼旁观的镜子。** 它基于扑克牌、五行生克和九宫洛书，帮助你把一个模糊的念头，投射成清晰可见的结构。通过量化差值、判断生克、推演天机线，让你看清自己当前认知的投射。

## 核心理念与设计哲学

- **逻辑先行，玄学为辅**：能用 5W2H、SWOT 等逻辑框架分析解决的实际问题，浮生牌会引导你先用逻辑推演。牌局只是在逻辑推演无法得出明确结论时，用来打破僵局的最后一块拼图。
- **规则透明，拒绝黑箱**：五行生克、差值计算、旺衰判定，所有推导过程在代码中完全开源呈现。用户可以在教程面板直接查阅底层规则。
- **本地优先，隐私绝对安全**：纯静态网页，所有数据仅在浏览器的 `localStorage` 中读写。**零数据收集，无后端服务器，无埋点分析。**
- **冷眼热心，不恐吓不逢迎**：基于实际的理论（六爻、奇门）给出客观断语。不制造焦虑、不贩卖改运物品、不窥探他人隐私。
- **去中心化设计**：网页只是辅助工具，你完全可以拿一副普通扑克牌，在纸上画出九宫格，独立完成整套观测。

## 核心功能

### 1. 起念 · 立极 · 观象（三步观测法）
- **起念**：默念或输入你当下的具体处境、问题，选择对应的领域（感情、事业、财运等）。
- **立极**：从 52 张扑克牌中挑出“体”（代表你）与“用”（代表外界环境）。
- **观象**：点击生成，系统将基于五行生克、天机线、差值、旺衰输出客观的占断结论。

### 2. 多维交叉观测体系
**基于 13 维的交叉推演：**
- 五行生克（体用关系）
- 九宫落位与宫位象意
- 数字差值（现实与理想的偏离程度）
- 天机线（起因、经过、结果）
- 旺相休囚死（能量状态）
- 四柱八字（时间底色）
- 求测姓名（个性化观测）
- 意图类别（感情、财运等定向映射）

### 3. 每日御神签（每日扑克牌抽牌）
每日自动根据日期生成一张独特的扑克牌。牌面通过五行色彩映射，直接展示每日启示，拒绝毫无依据的神棍文案。
*（注：今日状态牌会自动持久化，每日刷新一次，支持手动“重新抽牌”获取新状态）*

### 4. 替代占卜的逻辑推演工具
在教程面板中内置了 **5W2H**（Who/What/Where/When/Why/How/How much）与 **SWOT**（优势/劣势/机会/威胁）分析框架。当面对现实决策时，优先使用这些客观理性的工具分析局面。

### 5. AI 深度对话（可选增强）
- 用户自行填写 API Key（支持 DeepSeek、千问、OpenAI、Claude 等多家厂商）。
- AI 不会推翻规则引擎的结果，仅负责在既有结论基础上进行语言润色和心理逻辑梳理。
- 所有 AI 请求由用户浏览器**直连**第三方 API，不经过浮生牌的任何中转服务器。

### 6. 历史记录与 AI 追问复盘
历史记录会保留每一次占卜的详细牌局、宫位配置、天机线以及完整的 AI 对话记录。在历史详情中，你可以随时追加追问，系统会将历史解读带入上下文继续与 AI 探讨。

### 7. 伦理边界与精神力保护（观测者公约）
- 遵循“不戏卦、无事不占、一卦一断”的易学基本原则。
- 内置伦理拦截机制，拒绝涉及生死、赌博、窥探他人隐私、替人做重大决定等问题。
- 设有“子时提示”、“每日精神力用量”等防成瘾与提醒机制，引导用户健康使用。

## 技术架构与项目结构

浮生牌 100% 纯前端构建，采用 **Vite + 原生 JavaScript (ES Modules)**，**不引入任何 UI 框架**。所有代码可通过任何静态托管服务部署。

```
/
├── index.html              # 页面入口
├── style.css               # 暗夜金主题样式
├── vite.config.js          # Vite 构建配置
├── package.json            # 项目依赖
│
├── src/
│   ├── data.js             # 静态数据：五行、牌组、九宫、API配置
│   ├── engine.js           # 核心算法：洗牌、差值、天机线、四柱
│   ├── ai.js               # AI 厂商接口封装
│   ├── storage.js          # localStorage 读写与数据导出
│   ├── constants.js        # 可调数值常量
│   ├── state.js            # 全局状态管理
│   │
│   ├── ui/                 # UI 交互模块分离
│   │   ├── ui-render.js    # 所有页面结构渲染
│   │   ├── ui-drag.js      # 点按、长按、拖拽逻辑
│   │   ├── ui-modal.js     # 弹窗、Toast、引导
│   │   └── ui-anim.js      # CSS 动画注入
│   │
│   └── texts/              # 文案模块彻底分离
│       ├── texts-main.js   # 界面与按钮文案
│       ├── texts-readings.js # 六爻/奇门词库与生成引擎
│       ├── texts-reject.js # 伦理拒绝文案
│       ├── texts-spirit.js # 精神力提示文案
│       └── texts-tutorial.js # 教程与实体牌指南
```

## 快速开始与部署

### 本地运行
在终端执行以下三行命令：

```powershell
npm install
```

```powershell
npm run dev
```
浏览器打开 `http://localhost:5173` 即可使用。

### 构建与部署
执行构建命令：

```powershell
npm run build
```
生成的 `dist/` 文件夹可以部署到 **GitHub Pages、Netlify、Vercel** 等任何静态托管平台。
